# `figures/` — 그림 파일의 현재 상태

**요약: 세 PNG 모두 현재 논문 본문과 어긋난다. 이 상태로는 원고에 실을 수 없다.**

- 확인일: 2026-09-18
- 대조 대상: `paper/paper_draft.md`(영문 정본), `paper/paper_draft_ko.md`(한국어 판). 두 판의 해당 수치는 같다.
- 확인 방법: PNG를 직접 열어 눈으로 읽고, 논문 본문의 표·문장과 하나씩 대조했다. 그림을 다시
  만들거나 수치를 재계산하지는 않았다.

## 공통 사실

- **논문 본문이 이 그림들을 참조하지 않는다.** `paper_draft.md`와 `paper_draft_ko.md`에서
  `fig_`·`figures/`를 검색하면 두 판 모두 0건이다. 그림 번호도 캡션도 본문에 없다.
- **이 저장소에서는 재생성할 수 없다.** 세 그림을 만든 스크립트가 저장소에 없고
  (`savefig`·`matplotlib` 문자열 검색 0건), 파이프라인 가상환경에도 matplotlib이 없다.
- **파일이 오래됐다.** 세 PNG는 2026-08-02 커밋(`04b72ef`) 이후 내용이 바뀌지 않았다.
  논문 §4.5의 표와 §4.6–4.7의 설계는 그 뒤 7·8·9차 검토를 거치며 여러 번 바뀌었다.
- 아래에서 "본문 값"은 `paper/paper_draft.md`에서 읽은 값이고, "그림 값"은 PNG에서 읽은 값이다.

## 1. `fig_power_corrected.png`

### 무엇을 그린 그림인가

패널 두 개짜리 그림이다.

- **패널 a** — 제목 "정본: 비페어링 검정력 (기저 정확도 0.5 — 가장 보수적)".
  x축 "조건당 문제 수 (양쪽 균형, 비페어링)"에 50·100·164·200·400·800·1.6k·3.2k·6.4k,
  y축 "검정력". 교차효과 5pp·10pp·20pp 세 곡선, 검정력 0.80 가로 점선,
  "HumanEval 상한 164" 세로 점선.
- **패널 b** — 제목 "HumanEval을 주 조건으로 쓸 수 없는 이유 (낮을수록 좋음)".
  x축 "오염 조건 문제 수 (청정 조건 무제한 가정)"에 164·300·542·1k·2k·4k,
  y축 "검증 가능 최소 교차효과 (%p)". 주석 두 개: **"HumanEval 단독 (164) → 15.5pp"**,
  **"+MBPP+ (542) → 8.5pp"**. "낙관적 기대 10pp"·"현실적 기대 5pp" 가로 점선.

### 본문과 어긋나는 지점

1. **패널 b가 HumanEval과 MBPP+를 합쳐 놓았다.** 542 = HumanEval 164 + MBPP+ 378이다.
   본문 §4.2 표의 MBPP+ 행은 "**Not pooled** with HumanEval … The combined n=542 is a
   sample-size reference only, never a pooled analysis cell"이라고 적고, §3.0도
   "HumanEval and MBPP+ supply separate exploratory suspect-proxy contrasts; they are not
   pooled"라고 적는다. 그림은 이 금지된 합동 셀을 설계점으로 삼아 8.5%p라는 수치를 만든다.
2. **주 Q2 대비의 기준값이 그림에 없다.** 본문 §4.5.3은 주 LCB 대비의 최소 검출 가능
   교차효과를 **공유 대조 182문항 기준 14.7%p**, 최대 873문항 의심 외피를 가정해도 **16.1%p**로
   적는다. 패널 b에는 14.7도 16.1도 없고, 더 낙관적인 8.5%p가 결론 위치에 찍혀 있다.
3. 패널 b의 "HumanEval 단독 (164) → 15.5pp"는 본문 §4.2·§4.5.3의 15.5%p와 **일치한다.**
4. 패널 a는 §4.5.3의 비페어링 검정력 표(50/164/400/800/1,600/3,200 × 5/10/20pp)와
   내가 읽은 범위에서 **일치한다.** 다만 그림에서 소수 둘째 자리를 확정할 수는 없다
   (눈 판독 한계 약 ±0.02). 예컨대 1,600문항·5pp 셀의 본문 값 0.52와 그림 점의 차이는
   판독으로 가려지지 않는다.

### 다시 쓰려면 고칠 것

- 패널 b의 x축을 "오염 조건 문제 수(합동)"에서 주 Q2 대비의 실제 구성으로 바꾼다.
  공유 대조는 182로 고정돼 있으므로 이 축은 의심 셀 크기만 움직이는 축이어야 한다.
- 542 점과 "+MBPP+ (542) → 8.5pp" 주석을 지운다. 대신 182문항 대조 기준 14.7%p 하한과
  873문항 외피 가정의 16.1%p를 표시한다.
- 패널 a는 수정 없이 재사용할 수 있다. 다만 §4.5.3 표에 없는 100·200·6.4k 점은 표 밖의
  보간·외삽이므로 캡션에 그렇게 밝힌다.

## 2. `fig_round4_corrections.png`

### 무엇을 그린 그림인가

패널 두 개짜리 그림이다.

- **패널 a** — 제목 "두 효과는 분리된다 — 곱할 수 없다". y축 "조건당 필요 문제 수 (10pp 교차효과)".
  막대 네 개: 비페어링 p=0.5 → **785**, 비페어링 실제 기저율 → **557**, 페어링 p=0.5 → **549**,
  페어링 실제 기저율 → **419**. 빨간 가로선과 주석 **"문서 주장 '560 부근' = 785×(1−0.25) = 589"**.
- **패널 b** — 제목 "Q1b의 검정력 우위는 라벨 품질에 걸려 있다". x축 "오염 라벨 오류율 e (%)",
  y축 "Q1b에 필요한 문제 수 (각 조건)". 주석 "라벨 완벽 → 170", "e=20% → 541",
  "HumanEval 상한 164" 가로 점선, 그리고 빨간 가로선 **"Q2와 동급 (542)"**.

### 본문과 어긋나는 지점

1. **패널 a의 페어링 값 두 개가 모두 본문과 다르다.** 본문 §4.5.3의 분해 표는
   785 / 557 / **555** / **≈412**다. 그림은 **549**와 **419**로 그려져 있다.
   555는 σ=1.5 문항 난이도 모형의 함의 상관 r=0.293을 수치 적분으로 확정한 뒤의 값이고,
   549는 그 확정 이전 값이다.
2. **패널 a에 옛 주석이 남아 있다.** "문서 주장 '560 부근' = 785×(1−0.25) = 589"는 4차 검토가
   지적한 척도 혼합 오류를 보여 주려고 넣은 표시다. 현재 본문에는 "560 부근"이라는 주장도,
   785×(1−0.25)라는 계산도 없다. 본문 §4.5.3은 반대로 "multiplying reductions from incompatible
   scales is invalid"라고 적는다. 즉 그림이 반박하려는 대상이 본문에서 이미 사라졌다.
3. **패널 b의 빨간 기준선 표기가 틀렸다.** 그림은 "Q2와 동급 (542)"라고 적지만, 본문 §4.5.2는
   같은 문장을 "the same order as Q2's paired-model requirement (**≈555**)"로 적는다.
   542는 §4.5.2 잡음 표의 e=20% 행을 정수 올림한 값이지 Q2의 페어링 요건이 아니다.
4. 패널 b의 곡선 값 "170"과 "541"은 본문 §4.5.2의 잡음 감쇠 표(170/287/541/1,268)와
   **일치한다.**
5. **파일명 자체가 낡았다.** `round4`는 4차 검토 회차를 가리킨다. 본문은 9차 검토까지 왔고,
   패널 a는 4차 당시의 정정 이력을 보여 주는 그림이다. 원고용 그림 이름으로 쓸 수 없다.

### 다시 쓰려면 고칠 것

- 패널 a의 3·4번째 막대를 555와 ≈412로 고친다.
- "문서 주장 '560 부근' = 785×(1−0.25) = 589" 주석과 그에 딸린 빨간 가로선을 지운다.
  현재 본문에는 반박할 대상이 없다.
- 패널 b의 "Q2와 동급 (542)"를 본문 §4.5.2의 표현대로 "Q2 페어링 요건과 같은 규모 (≈555)"로
  고치고, 가로선 위치도 555로 옮긴다.
- 파일명을 개정 회차가 아니라 내용으로 바꾼다(예: 표본 수 분해 + 라벨 잡음 감쇠).
- 패널 b의 y축 "각 조건"은 본문 §4.5.2 표의 "per label group"(라벨 집단당)을 뜻한다.
  본문 표의 열 제목이 "Items per condition"이라 같은 모호함이 본문에도 있다(9차 검토 D-S7).
  그림을 다시 그릴 때 "라벨 집단당"으로 못박는 편이 낫다.

## 3. `fig_cdd_gate.png`

### 무엇을 그린 그림인가

패널 하나짜리 그림이다. 제목 "Q1b의 진입 조건은 문항 수가 아니라 CDD 기저 성능".
x축 "16bit 기준선에서의 CDD 기저 AUC (미확인 — 파일럿 측정 대상)" 0.5~1.0,
y축 "AUC 차이". 곡선 두 개 — 파란 실선 "양자화가 만드는 Δ AUC (μ  −10%)",
빨간 파선 "검출 한계 (542문항, r=0.8)". 두 곡선이 만나는 지점에 세로 점선과
**"관문: 기저 AUC ≈ 0.79"**. 왼쪽은 분홍 음영 **"Q1b 불가 구간"**,
오른쪽은 파란 음영 **"Q1b 성립 구간"**. 왼쪽 안에 빨간 주석
**"CDD가 우연 수준이면 Δ AUC → 0: 문항 수 무관하게 측정 불가"**.

**판독 불가:** 파란 실선 범례의 "(μ  −10%)"에서 μ와 −10% 사이에 글자 한 칸이 비어 있다.
확대해도 획이 전혀 없어(폰트 누락으로 보인다) 원래 어떤 기호였는지 알 수 없다.

### 본문과 어긋나는 지점

1. **데이터 의존 관문이 논문에서 없어졌다.** 그림 전체가 "기저 AUC 0.79를 넘어야 Q1b를
   수행한다"는 진입 관문 구조다. 본문 §4.6은 "In particular, CDD is not screened through a
   data-dependent gate"라고 적고, §4.7은 "CDD is not removed or demoted based on validation
   observations"라고 적는다. 관문 자체가 폐기된 설계다.
2. **파일럿이 논문에서 없어졌다.** x축 라벨의 "파일럿 측정 대상"은 파일럿에서 기저 AUC를
   재고 그 값으로 분석을 정하겠다는 뜻이다. 본문 §4.7의 제목은 "Fixed study analysis without a
   data-dependent pilot"이고 첫 문장이 "This design has no scientific pilot"이다.
3. **"Q1b 불가 구간"이라는 논리를 본문이 명시적으로 부정한다.** 본문 §2.4는 "Even if CDD's AUC
   remains 0.5 at both precisions, probability-based AUCs can change and a relative ranking can
   reverse … CDD's chance-level AUC alone does not make all of Q1b undetectable"라고 적는다.
   §4.5.6도 "A constant CDD score alone is not a reason to remove C4"라고 적는다.
   그림의 분홍 음영과 "문항 수 무관하게 측정 불가" 주석은 이 문장들과 정면으로 반대다.
4. **542문항이 설계점이 아니다.** 빨간 파선 범례의 "542문항"은 §4.5.2 AUC 표의
   542행을 쓴 것인데, 현재 본문의 그 행에는 "**hypothetical reference only**"라는 단서가 붙어
   있다. 확증 검정 C4가 실제로 쓰는 집단은 §4.5.6에 따라 690 대 182다.

### 다시 쓰려면 고칠 것

- 관문 구조를 버려야 한다. 제목·세로 점선·두 구간 음영·"Q1b 불가 구간" 주석이 모두
  관문 전제 위에 있으므로, 부분 수정이 아니라 목적부터 다시 정해야 한다.
- 이 그림을 살릴 방향이 있다면, "진입 여부"가 아니라 "기저 AUC가 낮을수록 Δ AUC 추정의
  불확실성이 커진다"는 정밀도 그림이다. 이때도 x축에서 "파일럿 측정 대상"을 빼고,
  542 대신 690/182를 쓰며, 왼쪽 구간을 "불가"가 아니라 "구간이 넓어지는 영역"으로 표시해야
  한다. 본문 §2.4와 §4.7의 문장을 그대로 따르는 표현이어야 한다.
- 범례의 렌더링되지 않은 글자는 어떤 기호였는지 모르므로, 재작성 시 수식을 새로 확정해야 한다.
