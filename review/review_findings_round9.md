### A-R1 / 주요 — Sela의 오염 주입 방식을 "LoRA만"으로 적음 **[재확인]**

- 위치: `paper_draft.md:152`, `:875`, `:877-879`
- 문구: *"controlled contamination injected via LoRA fine-tuning"* / *"the contamination in
  that paper is **injected via LoRA fine-tuning**"*
- 원문: LoRA r=8, LoRA r=256, 전체 미세조정(full fine-tuning) 세 방식. CDD가 가장 잘 작동한
  조건은 전체 미세조정 3 epoch (정확도 0.955).
- 근거: `pdfs/2603.03203.pdf` §1(변인 세 축), §3.3, 4쪽 Table 1(전체 미세조정
  70.4M/162.3M/405.3M), §4.3(0.955). 본 세션에서 `pdftotext -layout` 추출로 재확인.

  원문 설계와 어긋난다. 원문의 전체 미세조정은 모든 파라미터를 학습한다.

- 수정안: *"injected via fine-tuning (LoRA r=8/r=256 and full fine-tuning)"*. §6의 기전 차이는
  원문 Limitations 논지에 맞춰 "반복 주입된 미세조정 vs 반복 없는 사전학습 노출"로 적는다.

### D-S1 / 치명 — 변분 Bayes 구간이 95% 구간 역할을 못 함 **[재확인]**

- 위치: `paper_draft.md:683-686`
- 문구: *"mean-field variational Bayes approximation … approximate 95% credible intervals
  (mean ±1.96 posterior SD)"*. Q2는 "interval-focused"로 보고한다고 적혀 있다.
- 해석: mean-field 근사는 계수 간 사후 상관을 버린다. 2×2 처리 코딩에서 칸 크기가 같으면
  β_QE의 참 분산은 4/(wn), mean-field 분산은 1/(wn)이다. 정규 근사만으로도 SD가 절반이 되고,
  문항 랜덤 절편과의 상관이 더해지면 더 좁아진다.
- 모의실험 (영역 D, 60회): 모델 1개, 문항 690/182, 문항 난이도 SD 1.5, β_Q=−0.5, β_E=0.8,
  참 β_QE=0. `mixed_effects.py`와 같은 식으로 `fit_vb` 호출.
  - `fit_vb` 사후 SD 평균 **0.089**
  - 반복 간 추정값의 실제 표준편차 **0.272**
  - 문항 층화 조건부 로지스틱: SE 0.298, 포함률 95%
  - `fit_vb` ±1.96SD 구간이 참값 0을 포함한 비율 **50%**
- **[재확인]** 본 세션에서 시드를 바꿔 15회 재실행: 사후 SD 0.089, 실제 SD 0.275, 포함률 40%
  (조건부 로짓 SE 0.291, 포함률 100%). 결론 동일.
- 한계: 시나리오 하나로만 확인.
- 수정안: `fit_vb` SD로 구간을 만들지 않는다. 공분산 전체를 쓰는 방법(MCMC, 전체 헤시안 Laplace,
  glmer류 Wald/profile)으로 바꾼다. 모델별 적합이면 문항 층화 조건부 로짓도 가능하다.
  본 실행 전 합성 데이터 포함률 검증 단계를 §4.5.5에 명시한다.
